# Changelog

## [0.0.9] - 2026-10-06

### ✨ Added
- Cash on Delivery order emails: Notifications, shared email templates (layout, items, addresses, status, COD notice, button) and a `Sales Order Confirmation` print format, all under `hopkins/order_emails/`.
- Status-driven order emails sent from `Sales Order`, `Delivery Note` (validate / submit) and `Sales Invoice` (submit) events, with the order status remembered before submit to avoid duplicate sends.
- `Email Queue` hooks that render print-format attachments on insert and send the queued email immediately.
- `after_migrate` setup that installs the order email Notifications and print format.
- Tests for the order email flow (`order_emails/test_order_emails.py`).
- Webshop Settings fixture.
- Icon in the cookie banner header.
- Product card image and title now link to the item route.

### 🔧 Changed
- Overrode `place_order` and `cancel_order` from `invento_webshop` so Hopkins is Cash on Delivery only and tighter limits apply to who can cancel an order.
- Migrated builder files to standardized fixtures and updated the backend APIs accordingly.

### 🛡 Security
- Added safe redirection validation to the login client scripts.
