# Changelog

## [1.1.2] - 2026-10-12

### 🐞 Fixed
- Guest checkout signup (`storekit.webshop_functions.cart.place_order`) threw `PermissionError: No permission for Item` for the order's very own items. `create_user()` logs the guest in as the brand-new Website User partway through `place_order`, but the Quotation operations that follow (`add_items_to_quotation`, `update_cart_address`, `set_price_list_and_rate`, `calculate_taxes_and_totals`) ran under that user's own permissions - and a fresh Website User has no role granting Item read access. `quotation.flags.ignore_permissions` was only set right before `quotation.submit()`, well after those calls. It's now set as soon as the Quotation is obtained, for both the guest-signup and already-logged-in branches.
