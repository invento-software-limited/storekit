# Changelog

## [1.0.0] - 2026-10-08

First release of StoreKit, a generic Frappe/ERPNext ecommerce app that merges `invento_webshop` (v0.0.2) and `hopkins` (v0.0.9) into one app under the `StoreKit` module.

### ✨ Added
- All `invento_webshop` features: Webshop Settings and Webshop Theme (16 themes), storefront APIs (items, item groups, cart, checkout, address, register, invoice), variant selector, Lloyds Connect and Payment Gateway payments, Google Business reviews with a daily sync, Website Downloads, FAQ, Customer Reviews and the sitemap.
- All `hopkins` features: Cash on Delivery order emails (Notifications, email templates, `Sales Order Confirmation` print format), Case Study, Client Testimonial and Trusted Client DocTypes, and the enquiry, newsletter and products APIs (now `storekit.api.site`).
- Builder pages, components, client scripts, variables, tokens, fonts and assets from both apps; where both shipped the same component, the newer Hopkins version is kept.
- `storekit.setup.legacy_migration`, which runs after install on a site that has the old apps. It moves their DocTypes and module-linked records to `StoreKit`, moves Builder pages and project folders to the `storekit` app/folder, rewrites `invento_webshop.*` / `hopkins.*` method paths and `/assets/...` URLs stored in Builder, Notification and theme records, and deletes the old Module Defs so uninstalling the old apps afterwards drops no tables.
- `override_whitelisted_methods` aliases for every old `invento_webshop.*` / `hopkins.*` whitelisted method, so stale cached JS keeps working.
- StoreKit Workspace Sidebar and Desktop Icon, replacing the Hopkins ones.

### 🔧 Changed
- `required_apps` is now `erpnext` and `builder`.
- Fixtures were re-exported from the `hopkins.localhost` development site, so they include Builder edits that never made it into the old `hopkins` fixture files.
- The Webshop Settings section label "Invento Webshop Settings" is now "StoreKit Settings".
