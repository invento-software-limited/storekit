# Changelog

## [1.2.0] - 2026-11-08

### ✨ Added
- "Often purchased together" upsell section on the product page, shown above the reviews. `get_often_purchased_section()` in the new `storekit.api.often_purchased` module builds it from hand-picked items first, then items that appeared alongside this one in at least 2 submitted Sales Orders (a single shared order is treated as coincidence). Only published, non-template items with a price above £0 are shown, capped at 3 next to the current item, with a combined total. Any error is logged ("Often Purchased Section Error") and the section is hidden instead of breaking the page. `get_item_details_by_route()` returns it as `often_purchased`, and the product page's `page_data_script` exposes it to the Builder blocks.
- New child DocType **Often Purchased Item** and a "Recommended Items" table (`custom_often_purchased_items`) in its own section on Item, so staff can pick the upsell items for each product by hand.

### 🐞 Fixed
- Products with no image showed a broken image or an external `placehold.co` placeholder. Cart items (logged-in and guest), order confirmation items and `get_products()` now fall back to a local `/assets/storekit/builder_assets/product-placeholder.svg` (shared `PRODUCT_IMAGE_PLACEHOLDER` constant in `storekit.webshop_functions.cart`), and the Builder product-card image falls back to it on load error.
- Graphics that animate in with `fade-3d` stayed blurry after the animation. They are marked `crisp-graphic`, and a Builder Client Script rule drops the 3D layer once they're revealed so the browser redraws them at full resolution.

### ⚡ Performance
- Builder Settings `head_html`: the Toastify stylesheet now loads without blocking render, and the Google Fonts request only asks for the upright Poppins/Rubik weights the site uses (no italics).

### 🎨 Changed
- Testimonial quote marks now use a local `quote-marks.svg` asset.
