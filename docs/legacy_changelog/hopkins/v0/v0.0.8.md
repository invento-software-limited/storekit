# Changelog

## [0.0.8] - 2026-06-30

### ✨ Added
- Integrated the `ProductQuery` class from `invento_webshop` into `get_products` whitelisted API endpoint, enabling efficient filtering (by search and category) and robust pagination.
- Added clean CSS class configurations (`pagination-links` and `page-length-select`) to page JSON for targeted pagination selectors without exposing internal block IDs.
- Added dynamic pagination rendering support with an ellipsis (`...`) layout for navigation blocks when page numbers exceed 7.

### 🔧 Changed
- Converted the static Products page grid container into a dynamic **Repeater Block** bound to the backend `"products"` dataset.
- Cleaned up the product grid by removing static mock products and maintaining a single dynamic template card.
- Injected dynamic `dataKey` bindings into the `product_card` component to automatically render product images, titles, stock codes, and formatted selling prices.
- Removed sample dummy item seeding functions from `hopkins/api.py`.
