# Changelog

## [1.1.0] - 2026-10-08

### ✨ Added
- **Store Overview** Desk page (`/app/storekit-overview`) for System Manager and Sales Manager, with Company and period filters (7/30/90 days, this month, this year, custom) compared against the previous period of the same length:
  - KPI cards for web revenue (net of VAT and shipping, company currency), web orders, average order value, orders awaiting dispatch (by age), new customers (ordered vs not yet) and open carts (by idle time).
  - Order pipeline for orders placed in the period: In cart → Ordered → Part dispatched → Dispatched, to bill → Completed, plus Closed / On hold / Cancelled. Each stage opens the matching filtered list.
  - Revenue-over-time chart against the previous period, top 10 products, sales by item group, customer review ratings and catalog health (published items, items with no rate in the default selling price list, on sale, on backorder).
  - Worklists: orders to dispatch (oldest first, paginated), abandoned carts (idle over 24h), new customers without an order, lowest-rated recent reviews.
  - Data comes from one endpoint, `storekit.api.overview.get_dashboard_data`, built on permission-aware `frappe.get_list` queries. Web orders are Sales Orders with order type "Shopping Cart".
- StoreKit logo (shopping bag built from modular blocks) as solid and subtle desktop icons, the sidebar header icon and `app_logo_url`.
- StoreKit workspace sidebar: Store Overview and Builder links, then Orders, Catalog, Customers, Site Content and Notifications groups covering the related ERPNext and StoreKit DocTypes.

### 🔧 Changed
- The StoreKit desktop icon now uses the StoreKit logo instead of the leftover Hopkins screenshot image.

### 🐞 Fixed
- `install-app storekit` crashed on a fresh site with `DocumentLockedError`. Seven Builder components (Mobile Nav, Navbar, Item Card, Download Card, Cart Container, FAQ Component, Footer) were exported twice, under a readable folder name and under their record name, so Builder imported each one twice. The stale readable-name copies are removed.
- On a fresh install, the order-email Notifications, print format and custom fields are now created by `after_install` as well as `after_migrate`.
- `import_item_image.run_all` called test-data helpers it never imported, plus a `create_items` function that doesn't exist. It now imports them from `create_test_data` and uses `create_items_from_products`.
- Lint: the inherited code is formatted to the repo's ruff/prettier config, with no bare `except:` blocks, no unused variables, no duplicate dict keys or shadowed function definitions, and the dashboard JS declares its globals through `window`. `storekit/builder_files/` (Builder exports regenerated from the DB) is excluded from linting and formatting.
- CI installed Builder v1.24.7, which has no Builder Token DocType, so importing StoreKit's Builder Token fixtures failed. CI now uses Builder v1.34.0, the version the fixtures were exported from. Sites running StoreKit need Builder v1.33.0 or later.
